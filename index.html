I built your academic portfolio from scratch as a Vite + React + TypeScript app connected to Bolt Database. Here's what it does:

What's working now

  • A dark smoke-and-skull animated canvas background runs behind the whole app, with glassmorphism panels.
  • Login / Register screen with email + password authentication, plus a "Docente" (teacher) read-only access button. Registration captures your full name, university code, career, cycle, and profile photo.
  • Header with an editable UPLA logo, your profile card (avatar, name, code, career), and a logout button. Clicking your profile opens an "Editar Mi Perfil" modal where you can change your name, career, cycle, photo, and password.
  • Two courses (Algoritmos y Estructura de Datos, Desarrollo de Aplicaciones I), each with 4 units and all 16 weeks in the exact hierarchy you requested.
  • Each week lets you edit its topic, attach tasks two ways: a local file (uploaded to cloud storage) or a public cloud link (Google Drive / GitHub Releases), with an in-app guide explaining the cloud option. You can download and delete tasks.
  • Data lives in Bolt Database — users, profiles, weekly topics, and task metadata are in the database; uploaded files go to private Bolt Database Storage, downloaded via signed URLs. Each user only sees and edits their own data; the teacher mode can browse everyone's tasks read-only. Row Level Security and storage policies enforce this on the server side.

What you need to know

  • Your Bolt Database credentials are already wired up — no manual configuration needed.
  • Once you sign in from any device with the same account, all your tasks and profile reappear; reloading the page no longer loses anything.
  • The app runs automatically in the dev server; for publishing, the built dist/ folder is static and can go on any public host.

I verified the production build compiles cleanly and the database security linter reported zero issues. I couldn't test the live UI in a browser from here, so I'd recommend you try the mandatory test flow (register, upload a file, reload, log out and back in) once it's running.
